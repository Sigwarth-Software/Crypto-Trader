# Crypto-Trader-Development

Crypto-Trader-Development brings GitHub issue and project automation into the Crypto Trader platform. It provides an application environment where development work can be described consistently, published as issues, and organized within a shared project.

## What it enables

Teams can turn a development task into a structured work item with a description, checklist, labels, effort estimate, priority, and module ownership. Connecting issue creation with project organization helps keep the work backlog aligned with the platform's areas of responsibility.

The application combines GitHub connectivity with the platform's configuration and logging facilities. It relies on configured GitHub credentials and project access, along with the application's secrets, database, and messaging environment.

## Place in the platform

The Development libraries provide the issue vocabulary, communication contracts, integration services, and connection settings. This application brings those capabilities together for use within the running platform. Publishing creates real GitHub work items and project changes, so the configured repository and organization determine where that work appears.
