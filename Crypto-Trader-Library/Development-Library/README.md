# Development-Library

Development-Library is the shared foundation for organizing software development work through Crypto Trader. It groups the capabilities that connect a description of work to a GitHub issue and its place in a project backlog.

## What it enables

Development tasks can carry a consistent title, checklist, labels, estimates, and ownership information as they move from a proposal to a published issue. Shared conventions help people and automated tools describe work in the same terms.

The library family covers four areas: the meaning and structure of work items, the information exchanged with GitHub, the services that publish and organize issues, and the configuration that connects those services to an account and project.

## Place in the platform

Crypto-Trader-Development brings these capabilities together in an application. Other platform integrations can use the relevant Development modules for their own issue workflows. This directory groups that responsibility; the working capabilities are supplied by its individual modules.
