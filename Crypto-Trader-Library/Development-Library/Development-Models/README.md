# Development-Models

Development-Models defines what a development work item means within Crypto Trader. It provides a shared description of tasks, user stories, estimates, labels, priorities, and the platform areas responsible for the work.

## What it enables

A proposed change can be expressed as a title and explanation, supported by a task checklist and the metadata needed to plan it. Issue urgency and project priority remain separate concepts, allowing a work item to describe both its immediate importance and its position in the backlog.

The shared vocabulary also covers effort, size, type, and module ownership. Generated descriptions include a disclosure identifying their automated origin.

## Place in the platform

These definitions give development services and their callers a common language before anything is published. The services use them to prepare readable issues and organize those issues in GitHub. Repository-specific validation and remote publication happen in the integration layer.
